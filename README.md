# CPS222 HW5 - Dijkstra's Algorithm

An implementation of Dijkstra's shortest path algorithm using a custom `Graph` class and an extended `BetterPriorityQueue` class in C++.

## How to Compile and Run

Compile all programs:
```bash
make clean
make all
```

Run test suites:
```bash
./graph-tests
./bpq-tests
./dijkstra
```
